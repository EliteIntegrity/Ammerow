# Presentation colours for semantic terrain.  The default profile is the
# fallback for every location; biome profiles override only materials whose
# real-world identity changes there.  RGB values describe world materials,
# not interface chrome, and are therefore independent of the selected UI
# theme.
#
# profile <id>
# material <semantic material id>
# base <red> <green> <blue>
