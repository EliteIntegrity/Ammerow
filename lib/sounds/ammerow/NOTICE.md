The game includes 404 procedural sound effects and one Home theme.
The effects were created under human direction using Claude Code-assisted
Python synthesis software and cue recipes. Sample values were computed from
mathematical models and recorded seeds. No recordings, performers, third-party
samples, sample libraries, stock sounds or generative-audio service were used.
LAION CLAP was used to evaluate finished candidates, not to generate audio.

The Home theme was created separately with Claude Compose: AI-assisted code
placed the composition's notes, and licensed virtual instruments performed
them in Ableton Live. Rendered-audio analysis informed human-directed revision.
No generative audio/music model was used.
