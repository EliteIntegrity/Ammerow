# AMMEROW™: Lands Beyond

Ammerow is a turn-based roguelike combining overworld exploration, the Meridian
dungeon, side-view caves, climbing and fishing.

This source release builds a playable Windows SDL3 game using ASCII glyphs
and synthesised effects. Official downloads additionally contain separately
licensed ASCII illustrations, Hybrid 32x32/64x64 sprites and audio.

## Build and play

See [Building and testing](docs/building.md), [Data authoring](docs/data-authoring.md)
and [Packaging](packaging/README.md); [Randomness](docs/randomness.md) documents
the simulation's random streams and save contract. In the game, press F1 or ?
for the Field Guide.

Official playable releases include their corresponding program source in
`source/Ammerow-source.zip`. See [SOURCE-CODE.txt](SOURCE-CODE.txt) and the
[public repository](https://github.com/EliteIntegrity/Ammerow).
